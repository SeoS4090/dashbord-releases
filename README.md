## 설치와 첫 실행

1. [최신 Windows 릴리스](https://github.com/SeoS4090/dashbord-releases/releases/latest)의 **Assets**에서 x64 설치본을 받으세요. 일반 설치에는 `-setup.exe`를, MSI가 필요한 환경에서는 `.msi`를 선택하세요.
2. 설치 후 트레이의 Dashbord 아이콘을 더블클릭해 **설정 › 위젯**을 엽니다.
3. 위젯을 개별 창으로 띄우거나 **대시보드**에 타일로 모으세요. 자주 쓰는 배치는 프리셋으로 저장할 수 있습니다.

설치 경고, 편집 모드와 앱 내 업데이트 방법은 [설치 및 시작](guide/설치-및-시작.md)에서 확인하세요.
