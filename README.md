## Dashbord란?

Dashbord는 **바탕화면에 위젯을 띄워두는 개인용 대시보드 앱**입니다. 시계·달력·날씨처럼 자주 보는 정보, 출퇴근 체크인·메모 같은 생활 도구, 주식·코인·환율 시세, 그리고 개발자용 Claude 토큰 사용량까지 — 필요한 위젯만 골라 켜고, 원하는 위치에 끌어다 놓고, 항상 위에 띄울지 정할 수 있습니다.

- **떠 있는 오버레이** — 각 위젯은 테두리 없는 투명 창입니다. 바탕화면 위에 자연스럽게 얹혀 있고, 평소엔 조작 UI가 숨겨져 방해되지 않습니다.
- **카테고리** — 위젯은 **LIFE(생활) · GAME(게임) · DEV(개발)** 로 나뉩니다.
- **한국 중심** — 버스 도착·공휴일·미세먼지(공공데이터포털), 주식/환율(네이버·하나은행 고시), 코인(업비트), 로또(동행복권) 등 **국내 실시간 데이터** 위주로 연동되어 있습니다.
- **트레이 상주** — 메인 창은 숨겨져 있고, 작업 표시줄 트레이 아이콘으로 동작합니다. 창을 모두 닫아도 앱은 트레이에 남아 있습니다.

> 코드 서명이 없는 **개인용 앱**입니다. 회사 배포용이 아니며, 데이터는 모두 내 PC에만 저장됩니다(아래 [내 데이터는 어디에 저장되나요?](#내-데이터는-어디에-저장되나요) 참고).

## 설치

1. **[Releases](https://github.com/SeoS4090/dashbord-releases/releases) 페이지**에서 최신 버전의 설치 파일을 받습니다.
   > 설치본은 공개 배포 저장소 [`dashbord-releases`](https://github.com/SeoS4090/dashbord-releases) 에 올라갑니다(소스는 비공개).
   - `dashbord_X.Y.Z_x64-setup.exe` — **권장**(NSIS 설치 관리자). 자동 업데이트를 지원합니다.
   - `dashbord_X.Y.Z_x64_en-US.msi` — MSI 설치 파일(기업 환경 등).
2. 설치 파일을 실행합니다.
3. **"Windows의 PC 보호(SmartScreen)" 경고가 뜨면** → `추가 정보` → `실행`을 누릅니다.
   - 이 앱은 비용 문제로 **코드 서명을 하지 않았기 때문에** 처음 한 번은 경고가 뜹니다. 정상이며, 한 번 실행하면 이후엔 뜨지 않습니다.
4. 설치가 끝나면 트레이에 Dashbord 아이콘이 나타납니다.

> **업데이트**는 앱 안에서 처리됩니다. 트레이 → `업데이트 확인` 또는 설정 → 정보에서 새 버전을 받아 설치할 수 있어요(설치 관리자 버전 기준).

## 처음 켜면 — 5분 시작 가이드

1. **트레이 아이콘을 더블클릭**하면 설정 창이 열립니다.
2. **설정 › 위젯** 탭에서 원하는 위젯의 스위치를 켜면, 바로 바탕화면에 떠오릅니다.
3. 위젯 위치를 바꾸려면 **트레이 › 편집 모드 전환**을 켜고, 위젯 상단 손잡이를 끌어 옮깁니다. 다 옮겼으면 편집 모드를 다시 끕니다.
4. 버스·캘린더·Jira 같은 **연동이 필요한 위젯**은 **설정 › 연동** 탭에서 키/계정을 한 번 등록하면 됩니다([연동 설정](#연동토큰계정-설정--핵심) 참고).
5. PC를 켤 때 자동으로 실행되게 하려면 **설정 › 일반 › 시작 프로그램**을 켜세요.

## 기본 사용법

### 위젯 추가 / 제거
- **설정 › 위젯** 탭 → 카탈로그에서 위젯 스위치를 켜면 추가, 끄면 숨김(위치·설정은 보존).
- 같은 위젯을 **여러 개** 띄울 수도 있습니다(예: 세계 시계 여러 도시). 위젯 카드를 펼쳐 `+ 추가`.
- 위쪽 검색창으로 위젯을 빠르게 찾을 수 있습니다.

### 편집 모드 — 옮기고 / 크기 조절 / 고정
- **트레이 › 편집 모드 전환** (또는 설정 › 일반 › 편집 모드)을 켜면 위젯에 **드래그 손잡이**와 **크기 조절 핸들**이 나타납니다.
- 위젯을 원하는 위치·크기로 맞춘 뒤 편집 모드를 끄면 깔끔한 평소 모습으로 돌아갑니다.
- 위치·크기는 자동 저장되어 앱을 재시작해도 그대로 유지됩니다.

### 항상 위에 띄우기 (z-순서)
- 설정 › 위젯에서 위젯 카드를 펼치면 **`일반` / `항상 위`** 를 고를 수 있습니다.
- `항상 위`로 두면 다른 창 위에 늘 보이고, `일반`이면 다른 창에 가려질 수 있습니다.

### 대시보드 — 여러 위젯을 한 창에 묶기
- **대시보드** 위젯은 여러 위젯을 **타일 그리드**로 한 창에 모아 보여줍니다.
- 창 여러 개 대신 하나로 합치면 메모리 사용도 줄어듭니다. 타일은 대시보드 설정에서 추가·배치할 수 있습니다.

### 시스템 트레이 메뉴
- **YouTube / YouTube Music / X** — 무거운 외부 창 위젯을 빠르게 켜고 끄는 토글(체크 표시).
- **편집 모드 전환 · 설정 열기 · 업데이트 확인 · 종료**.
- 트레이 아이콘 **더블클릭** → 설정 창.

### 자동 시작 · 업데이트
- **시작 프로그램**(설정 › 일반): 윈도우 부팅 시 자동 실행.
- **업데이트 확인**(트레이/설정 › 정보): 새 버전을 받아 자동 설치·재시작.

## 연동(토큰/계정) 설정 — 핵심

대부분의 위젯은 **아무 설정 없이 바로** 쓸 수 있습니다. 다만 아래 몇몇 위젯은 외부 서비스의 데이터를 가져오기 때문에 **키 또는 계정 연결**이 필요합니다. 연결은 모두 한 곳, **설정 › 연동** 탭에서 관리합니다.

> **여는 법:** 트레이 아이콘 더블클릭 → 설정 창 → 왼쪽 **`연동`** 탭.

### 왜 토큰을 넣어야 하나요?

- 버스 도착 정보, 공휴일, 미세먼지 같은 데이터는 **정부 공공데이터포털**이 제공하는데, 무분별한 호출을 막기 위해 **개인별 발급 키**를 요구합니다. Dashbord에 내 키를 넣어줘야 그 데이터를 받아올 수 있습니다.
- Google 캘린더·Jira처럼 **내 개인 계정의 데이터**는, 내가 직접 권한을 허용해야만 앱이 읽을 수 있습니다(보안상 당연한 절차예요).
- **귀찮아도 한 번만 설정하면 됩니다.** 키/계정은 최초 1회만 등록하면, 이후엔 앱이 알아서 갱신·사용합니다.
- **어디에 저장되나요?** API 키·토큰은 설정 파일(JSON)에 **절대 들어가지 않고**, **Windows 자격 증명 관리자(Credential Manager)** 에 안전하게 저장됩니다. 캘린더는 비밀번호 대신 Google 공식 OAuth 동의 화면을 거치므로, 앱이 비밀번호를 보지 않습니다.

설정 › 연동 화면에는 세 가지 카드가 있습니다: **공공데이터포털 · Google 캘린더 · Jira**.

### 🔑 ① 공공데이터포털(data.go.kr) 키

**무엇에 쓰나요?** 하나의 키로 아래 세 가지 데이터를 받아옵니다.

| 기능 | 위젯 | 키 없으면? |
|---|---|---|
| 실시간 **버스 도착** | 버스 도착 | ❌ **동작 안 함** (도시/정류장 목록을 못 불러옴) |
| **미세먼지/대기질** | 날씨(선택 표시) | ⚠️ 날씨는 정상, 미세먼지만 안 나옴 |
| **공휴일** 표시 | 캘린더 | ⚠️ 일정은 정상, 빨간날 표시만 안 됨 |

→ **버스 도착 위젯을 쓰려면 키가 반드시 필요**하고, 날씨·캘린더는 키가 없어도 핵심 기능은 멀쩡합니다.

**키 발급 방법**
1. [공공데이터포털(data.go.kr)](https://www.data.go.kr/) 에 가입/로그인합니다.
2. 필요한 API를 검색해 **"활용신청"** 합니다(보통 즉시 승인):
   - 버스 → **국토교통부 TAGO(대중교통정보)** 의 버스도착정보·버스정류소 관련 API
   - 미세먼지 → **한국환경공단 에어코리아 대기오염정보**
   - 공휴일 → **한국천문연구원 특일 정보**
3. **마이페이지 → 인증키**에서 **"일반 인증키(Decoding)"** 값을 복사합니다.
   - ⚠️ **Encoding**이 아니라 **Decoding** 키를 넣어야 합니다.

**앱에 등록**
1. 설정 › 연동 → **"공공데이터포털 (data.go.kr)"** 카드.
2. 입력란에 Decoding 키를 붙여넣고 **`저장`**.
3. `저장됨` 배지가 뜨면 완료. (삭제하려면 `삭제`.)

> 키는 계정당 하나면 되며, 위에서 **활용신청한 API들 모두**에 같은 키가 적용됩니다. 어떤 데이터가 안 나오면 그 API의 활용신청이 승인됐는지 확인하세요.

### 🔗 ② Google 캘린더 연결

**무엇에 쓰나요?** **캘린더** 위젯에 내 Google 캘린더 일정을 표시합니다.
**선택사항입니다** — 연결하지 않아도 캘린더 위젯은 **앱에 직접 추가한 일정/출퇴근 일정**을 그대로 보여줍니다. Google 일정을 함께 보고 싶을 때만 연결하세요.

**준비물 (Google Cloud Console, 무료)**
1. [Google Cloud Console](https://console.cloud.google.com/) → 프로젝트 생성.
2. **Google Calendar API** 사용 설정.
3. **사용자 인증 정보 → OAuth 클라이언트 ID 만들기 → 애플리케이션 유형: 데스크톱 앱**.
4. 생성된 **클라이언트 ID**와 **클라이언트 보안 비밀(secret)** 을 복사.

**앱에 연결**
1. 설정 › 연동 → **"Google 캘린더"** 카드.
2. **클라이언트 ID** / **클라이언트 secret** 입력 → **`연결`**.
3. 브라우저에 Google 동의 화면이 뜹니다 → **읽기 전용 권한 허용**.
4. `연결됨: 내메일@gmail.com` 배지가 뜨면 완료. (해제는 `연결 해제`.)
5. 어떤 캘린더를 표시할지는 **캘린더 위젯 설정**에서 고릅니다.

> ⚠️ **7일마다 끊긴다면?** Google OAuth 동의 화면이 **"테스트" 상태**면 토큰이 7일마다 만료됩니다. Cloud Console에서 동의 화면을 **"프로덕션으로 게시"** 하면 재연결 없이 계속 유지됩니다.
> 🔒 비밀번호는 앱에 입력하지 않습니다(Google 공식 화면에서만 로그인). 토큰은 Windows 자격 증명 관리자에 저장됩니다.

### 🔗 ③ Jira 연결

**무엇에 쓰나요?** **Jira 칸반** 위젯에 내 보드 이슈를 상태별로 표시합니다.
**이 위젯은 연결이 필수**입니다 — 연결 전에는 위젯이 "설정 › 연동에서 연결하세요" 안내만 보여줍니다.

**API 토큰 발급**
1. [Atlassian API 토큰 페이지](https://id.atlassian.com/manage-profile/security/api-tokens) 접속.
2. **"Create API token"** → 이름 짓고 생성 → **토큰 복사**.

**앱에 연결**
1. 설정 › 연동 → **"Jira"** 카드.
2. 입력:
   - **호스트** — 예: `회사이름.atlassian.net` (`https://`·끝 슬래시 없이)
   - **이메일** — Atlassian 계정 이메일
   - **API 토큰** — 위에서 복사한 토큰
3. **`연결 테스트`** 로 먼저 확인하거나, 바로 **`저장`**.
4. `연결됨: 내메일` 배지가 뜨면 완료.
5. 어떤 **보드/JQL**을 볼지는 **Jira 위젯 설정**에서 고릅니다.

> 토큰은 자격 증명 관리자에만 저장되고, 로그나 설정 파일엔 절대 기록되지 않습니다.

### 🔗 ④ 계정 로그인 (YouTube · YouTube Music · X)

이 세 위젯은 실제 웹사이트를 **별도의 데스크톱 창**으로 띄웁니다. 로그인은 **선택사항**이지만, 로그인하면 내 구독·재생목록·피드가 그대로 보입니다.

**계정(세션) 방식**
- 각 위젯은 **세션(독립 로그인 프로필)** 에 연결됩니다. 쿠키/로그인은 그 프로필에 저장되어 **앱을 꺼도 유지**됩니다.
- 같은 세션을 여러 위젯이 공유하면 **로그인 한 번으로 공유**되고, 세션을 따로 만들면 **계정을 분리**할 수 있습니다(예: 개인/회사 유튜브).

**로그인 방법**
1. 설정 › 위젯에서 해당 위젯(예: YouTube)을 펼쳐 **`설정`**.
2. **계정(세션)** 영역에서 `+ 새 세션`으로 세션을 만들고(이름·이메일 입력) 선택, 또는 기본 프로필 사용.
3. **`로그인`** → 로그인 창이 뜨면 해당 사이트에 로그인 → 창을 닫습니다.
4. 위젯을 새로 고치면 로그인된 내용이 표시됩니다. 계정을 바꾸려면 다른 세션을 선택하세요.

> 외부 창 위젯은 메모리를 많이 쓰므로, 필요할 때만 **트레이에서 빠르게 켜고 끌** 수 있습니다.

### ⑤ Claude 사용량 — 키 불필요

**사용량** 위젯은 **API 키가 전혀 필요 없습니다.** 로컬에 쌓이는 Claude Code 사용 기록(`~/.claude` 하위 JSONL)을 **오프라인으로 직접 읽어** 토큰 사용량·비용을 집계합니다.

- **다계정 합산**: 회사·개인 등 여러 Claude 설정 폴더를 동시에 볼 수 있습니다.
- **설정 방법**: 위젯 설정의 **계정** 영역에서 폴더를 추가합니다(자동 탐색된 폴더에서 고르거나 경로 직접 입력). 예: 기본 `~/.claude`, 추가 `D:\claude-personal`.

## 토큰이 꼭 필요한가요? (한눈에 보기)

**대부분의 위젯은 키가 전혀 필요 없습니다.** 아래 위젯만 설정이 필요합니다.

| 연동 | 대상 위젯 | 필수 / 선택 | 없으면 |
|---|---|---|---|
| **공공데이터포털 키** | 버스 도착 | **필수** | 위젯이 동작 안 함 |
| **공공데이터포털 키** | 날씨(미세먼지) | 선택 | 날씨는 정상, 미세먼지만 빠짐 |
| **공공데이터포털 키** | 캘린더(공휴일) | 선택 | 일정은 정상, 공휴일만 빠짐 |
| **Google 캘린더** | 캘린더 | 선택 | 로컬 일정만 표시 |
| **Jira** | Jira 칸반 | **필수** | 안내문만 표시 |
| **계정 로그인** | YouTube / YT Music / X | 선택 | 비로그인 상태로 표시 |

**키·로그인이 전혀 필요 없는 위젯:** 대시보드, 시계, 타이머, 출퇴근, 메모, D-Day, 런처, 코인, RSS, 주식, 로또, 환율, 사운드 믹서, 미디어, 블루투스, 시스템(하드웨어), Claude 사용량, GitHub 트렌딩, Hacker News, Tarkov, 치지직, Idle Game.

## 내 데이터는 어디에 저장되나요?

모든 데이터는 **내 PC에만** 저장됩니다. Dashbord는 별도 서버로 데이터를 보내지 않으며, 각 위젯이 표시를 위해 **해당 공개 API(공공데이터포털·네이버·업비트·Google 등)** 를 직접 호출할 뿐입니다.

| 종류 | 위치 |
|---|---|
| 위젯 구성·레이아웃·설정 | `%APPDATA%\com.dashbord.app\config.json` |
| 일정·메모·출퇴근 이력 등 | 앱 데이터 폴더의 SQLite DB |
| **API 키 / 토큰 / 로그인** | **Windows 자격 증명 관리자** (설정 파일엔 미기록) |
| 계정 로그인 쿠키(YouTube 등) | 앱 데이터 폴더의 세션 프로필 |

> ⚠️ `config.json`을 직접 편집할 일이 있다면 **UTF-8 BOM 없이** 저장하세요(BOM이 있으면 파싱에 실패해 기본값으로 초기화됩니다).

## 자주 묻는 질문 / 문제 해결

**Q. 설치할 때 "Windows의 PC 보호" 경고가 떠요.**
코드 서명을 하지 않은 개인용 앱이라 그렇습니다. `추가 정보 → 실행`을 누르면 됩니다. 한 번만 거치면 됩니다.

**Q. 앱을 껐다 켜면 위젯이 처음 위치로 돌아가요 / 점점 작아져요.**
고해상도(125%·150% 등 배율) 디스플레이에서 위치가 어긋나던 문제는 최신 버전에서 수정되었습니다. 업데이트 후 위젯을 원하는 위치에 한 번 놓으면 이후로는 그대로 유지됩니다.

**Q. 버스/미세먼지/공휴일이 안 나와요.**
설정 › 연동에서 **공공데이터포털 키**가 `저장됨` 상태인지, 그리고 data.go.kr에서 **해당 API의 활용신청이 승인**됐는지 확인하세요. (Decoding 키여야 합니다.)

**Q. Google 캘린더가 7일마다 끊겨요.**
Google Cloud Console에서 OAuth 동의 화면을 **"프로덕션으로 게시"** 하세요. 테스트 상태에서는 토큰이 7일마다 만료됩니다.

**Q. 입력한 키/토큰은 안전한가요?**
네. 모두 **Windows 자격 증명 관리자**에 저장되며 설정 파일·로그에는 남지 않습니다. 캘린더는 비밀번호 대신 Google 공식 OAuth만 사용합니다.

**Q. 창을 다 닫았는데 앱이 안 꺼져요.**
의도된 동작입니다. 앱은 트레이에 상주합니다. 완전히 종료하려면 **트레이 → 종료**.

**Q. YouTube Music을 최소화했더니 사라졌어요.**
백그라운드 재생 기능입니다. 창은 숨고 음악은 계속 재생되며, **미디어 위젯 우측 상단의 복원 아이콘**(또는 트레이의 YouTube Music 토글)으로 다시 띄울 수 있습니다.
