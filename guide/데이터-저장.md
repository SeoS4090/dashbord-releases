# 🔒 내 데이터는 어디에 저장되나요?

---

위젯 배치와 개인 기록은 PC에 저장합니다. 온라인 위젯은 표시할 정보를 해당 서비스에서 조회하며, 계정을 연결한 위젯은 그 계정의 권한으로 요청합니다.

| 종류 | 위치 |
|---|---|
| 위젯 구성·레이아웃·설정 | `%APPDATA%\com.dashbord.app\config.json` |
| 직접 입력한 일정·출퇴근 이력 | 앱 데이터 폴더의 SQLite DB |
| 메모함·체크리스트 | 앱 데이터 폴더의 `notes.json`. 프리셋을 바꾸거나 위젯을 제거해도 유지됩니다. |
| GitHub 즐겨찾기 | 앱 데이터 폴더의 `github-favorites.json`. 모든 프리셋에서 같은 목록을 사용합니다. |
| **연동 설정의 API 키 / 토큰** | **Windows 자격 증명 관리자** (설정 파일엔 미기록) |
| 계정 로그인 쿠키(YouTube 등) | 앱 데이터 폴더의 세션 프로필 |

> ⚠️ `config.json`을 직접 편집할 일이 있다면 **UTF-8 BOM 없이** 저장하세요(BOM이 있으면 파싱에 실패해 기본값으로 초기화됩니다).
